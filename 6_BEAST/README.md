## Divergence time estimation with BEAST2 and SNAPP

We estimated species divergence times from genome-wide SNPs with the BEAST2 package [SNAPP](https://www.beast2.org/snapp/), using three representative non-admixed individuals per taxon (Text S3, Figure S19). The approach follows Michael Matschiner's [snapp_prep](https://github.com/mmatschiner/snapp_prep/) script and [SNAPP tutorial](https://github.com/ForBioPhylogenomics/tutorials/blob/main/divergence_time_estimation_with_snp_data/README.md).

### Input

* `data/pteropus_samples_snapp.txt`: the 15 selected samples (3 each of SFF, BFF, GHFF, LRFF and IBFF = *P. alecto alecto*).
* `data/pteropus_constraints.txt`: the calibration. The crown group of all taxa except *P. scapulatus* has a lognormal age prior (offset 0, mean 1.26 in real space, SD 0.1), based on the time tree of [Almeida et al. (2014)](https://www.sciencedirect.com/science/article/pii/S1055790314001092). The group is constrained to be monophyletic.
* `data/pteropus_starting_tree.nwk`: the starting topology `(LRFF,(GHFF,(IBFF,(BFF,SFF))))`, based on the RAxML analysis (`3_SNP_Structure`) and the literature.
* `data/pteropus_beast2_snapp.xml`: the BEAST2 input generated by `snapp_prep.rb`. It contains the SNP data of the 15 samples.

The SNP data were taken from the filtered unlinked SNPs in `1_SNP_Calling/data/pteropus.vcf.gz`, restricted to the selected samples. For example:

```
tail -n +2 data/pteropus_samples_snapp.txt | cut -f2 > snapp_samples.txt
bcftools view -S snapp_samples.txt -Oz -o pteropus_beast2.vcf.gz ../1_SNP_Calling/data/pteropus.vcf.gz
```

*Note:* by default, the lognormal mean in the `snapp_prep.rb` XML is in real space (`meanInRealSpace="true"`). The offset is not in real space.

### Running SNAPP

```
packagemanager -add SNAPP
wget https://raw.githubusercontent.com/mmatschiner/snapp_prep/master/snapp_prep.rb
gunzip pteropus_beast2.vcf.gz
ruby snapp_prep.rb --vcf pteropus_beast2.vcf --table data/pteropus_samples_snapp.txt --xml pteropus_beast2_snapp.xml \
    --constraints data/pteropus_constraints.txt --length <chain_length> --starting-tree data/pteropus_starting_tree.nwk
beast -threads 32 pteropus_beast2_snapp.xml
```

The run was stopped after about 43 million MCMC generations (the last state in the log), once convergence had been reached. Convergence was assessed in Tracer. A maximum clade credibility tree with mean node heights was produced with TreeAnnotator:

```
treeannotator -heights mean -burnin <burnin_percent> pteropus_beast2_snapp.trees pteropus_beast2_snapp.mean_height.tre
```

### Results

* `results/pteropus_beast2_snapp.log.gz`: MCMC parameter log.
* `results/pteropus_beast2_snapp.trees.gz`: sampled trees.
* `results/pteropus_beast2_snapp.mean_height.tre`: MCC tree with mean node heights in millions of years (Figure S19). The figure was drawn using FigTree.

The `chainLength` in the provided XML (5,000,000) is lower than the number of generations in the log because multiple shorter runs like this were combined to generate the final result.
